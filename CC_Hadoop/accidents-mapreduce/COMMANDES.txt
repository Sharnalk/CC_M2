MEMO COMMANDES - SOUTENANCE SUJET 3
(a lancer depuis le dossier accidents-mapreduce/)

===========================================
1. DEMARRER LE CLUSTER (si pas deja lance)
===========================================
docker-compose up -d
docker exec -it hadoop-runner jps
    -> doit lister ResourceManager

===========================================
2. VERIFIER QUE TOUT TOURNE (optionnel, complet)
===========================================
docker exec -it namenode jps       -> NameNode
docker exec -it datanode jps       -> DataNode
docker exec -it hadoop-runner jps  -> ResourceManager
docker exec -it nodemanager jps    -> NodeManager

===========================================
3. ENVOYER LES DONNEES SUR HDFS (1re fois seulement)
===========================================
docker exec -it hadoop-runner bash -c "hdfs dfs -mkdir -p /user/hadoop/input /lookup"
docker exec -it hadoop-runner bash -c "hdfs dfs -put /data/accidents.csv /user/hadoop/input/accidents.csv"
docker exec -it hadoop-runner bash -c "hdfs dfs -put /data/communes.csv /lookup/communes.csv"

===========================================
4. LANCER LE JOB
===========================================
mvn clean package
docker exec -it hadoop-runner bash -c "hadoop jar /programs/accidents-mapreduce.jar com.tp.accidents.AccidentsDriver"

===========================================
5. LIRE LE RESULTAT
===========================================
docker exec -it hadoop-runner bash -c "hdfs dfs -cat /user/hadoop/output/part-r-00000"

===========================================
6. RELANCER APRES UNE MODIF DE CODE (boucle)
===========================================
mvn clean package
docker exec -it hadoop-runner bash -c "hdfs dfs -rm -r -f /user/hadoop/output"
docker exec -it hadoop-runner bash -c "hadoop jar /programs/accidents-mapreduce.jar com.tp.accidents.AccidentsDriver"
docker exec -it hadoop-runner bash -c "hdfs dfs -cat /user/hadoop/output/part-r-00000"

    IMPORTANT : l'etape "hdfs dfs -rm -r -f" est obligatoire avant de relancer,
    sinon Hadoop refuse d'ecrire dans un dossier de sortie qui existe deja.

===========================================
7. SUPPRIMER / NETTOYER
===========================================
Supprimer juste la sortie du Job :
    docker exec -it hadoop-runner bash -c "hdfs dfs -rm -r -f /user/hadoop/output"

Voir ce qu'il y a sur HDFS :
    docker exec -it hadoop-runner bash -c "hdfs dfs -ls /user/hadoop/input"
    docker exec -it hadoop-runner bash -c "hdfs dfs -ls /lookup"

===========================================
8. INTERFACES WEB (a montrer a l'oral, plus parlant qu'un terminal)
===========================================
HDFS (fichiers stockes)     : http://localhost:9870
YARN (suivi des Jobs)       : http://localhost:8088

===========================================
9. TOUT ARRETER (en fin de demo)
===========================================
docker-compose down
    (garde les donnees HDFS pour la prochaine fois)

docker-compose down -v
    (repart de zero, efface aussi les donnees HDFS)
